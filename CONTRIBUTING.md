# Contributing / Katkı

Open an issue describing the user problem, then make a focused pull request. Never attach tokens, production `.env`, member profiles or private server metadata. Keep UI and setup instructions in Turkish and English. Preserve minimal permissions, fresh role/channel safety checks, explicit one-use personal confirmation and singular role operations. Changes to authorization policy need specific negative/concurrency tests and README risk updates. Avoid adding privileged intents, telemetry, automatic assignment or external authorization.

Use Node 24.x. Run `npm ci --ignore-scripts`, `npm run check`, `npm audit --audit-level=low`, `node --check scripts/setup.mjs`, `node --check scripts/supply.mjs`, and `bash -n setup.sh register.sh start.sh`. To format, run `npm exec biome check -- --write .`. CI uses Windows, Ubuntu, macOS 15 Intel. Tests mock Discord; report live tests honestly and use a dedicated test server/application. Do not test role changes on an unsuspecting community. Retain license notices and review lockfile changes.

Türkçe: Önce kullanıcının sorununu açıklayan bir issue açın; odaklı PR hazırlayın. Token, gerçek `.env`, üye profili veya özel sunucu bilgisi eklemeyin. Türkçe/İngilizce arayüz ve belgeleri koruyun. Minimum izin, güncel rol/kanal güvenliği, kişisel tek kullanımlık açık onay ve tekil rol işlemi gereklidir. Yetki kuralı değişiminde olumsuz/eşzamanlılık testleri ve risk belgelerini güncelleyin. Ayrı test sunucusu/uygulaması kullanın; topluluk üzerinde habersiz deneme yapmayın. Yukarıdaki komutları çalıştırın, kilit dosyası/lisans değişimlerini inceleyin ve gerçek canlı doğrulama kapsamını açıkça yazın.
