# Security / Güvenlik

Use a dedicated application/token, one process and only View Channel, Send Messages, Manage Roles. Never grant Administrator. Keep the bot below administrative/access roles. Allowlist only cosmetic roles with zero permissions/no channel overwrites, never roles consulted by other authorization services. A member must already hold a higher role before adding cosmetics. Do not repurpose assigned cosmetics into permission-bearing roles. Inspect all existing assignments first.

Fresh checks are best effort, not an atomic Discord transaction. Stop the bot while changing critical permission/role settings. A stolen token bypasses application safeguards and can manage roles below the bot. Rotate it immediately, stop the compromised host and review Discord audit logs. This application does not reverse role assignments automatically. Old panels persist; deleting a panel does not cancel pending confirmations. Stopping the process clears pending previews. Failed/uncertain changes are never automatically retried; check actual state.

Keep Node 24 and dependencies maintained. `npm ci --ignore-scripts` prevents lifecycle scripts. CI is read-only and action references are pinned. Supply scans check registry/integrity/licenses and credential patterns, not every possible vulnerability. Do not publish credentials or member data in a report. Use GitHub **Security → Report a vulnerability** if available. If unavailable, open a minimal issue asking for a private reporting channel, without exploit details/secrets. The operator must handle policy reports and incident notification obligations under Discord terms.

Türkçe: Ayrı uygulama/token, tek süreç ve yalnızca üç gerekli izni kullanın; Yönetici vermeyin. Bot rolünü yönetim/erişim rollerinden aşağıda tutun. İzin listesi yalnızca sıfır izinli, kanal kaydı olmayan, başka hizmetlerde yetkilendirme için kullanılmayan kozmetik roller içermeli. Üyede kozmetik rolden daha yüksek mevcut rol olmalı. Verilmiş kozmetik rolleri incelemeden yetki rolüne dönüştürmeyin.

Güncel kontroller Discord'da atomik işlem değildir. Kritik izin değişiminde botu durdurun. Çalınan token uygulama kontrollerini aşar; hemen sıfırlayın, hostu durdurun, Discord denetim kayıtlarını inceleyin. Bot geçmiş rol atamalarını otomatik geri almaz. Panel silme bekleyen onayı iptal etmez; süreç durdurma belleği temizler. Belirsiz işlem tekrarlanmaz; gerçek durumu kontrol edin.

Node ve bağımlılık güncellemelerini takip edin. Güvenlik raporunda token/üye verisi paylaşmayın. Varsa GitHub Security → Report a vulnerability kullanın; yoksa ayrıntı/sır içermeyen bir issue ile özel bildirim kanalı isteyin. Tarama tüm açıkları bulma garantisi değildir. Operatör Discord şartlarına uygun olay/politika bildirimlerini ele almalıdır.
